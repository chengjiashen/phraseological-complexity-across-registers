# ENCOW16AX Reference Data

This directory documents the reference data derived from ENCOW16AX and used
to calculate frequency-, association-, and dispersion-based measures of
phraseological complexity.

The reference data include:

- lemma frequencies;
- frequencies of dependency-based two-word combinations;

Because of file-size and redistribution restrictions, the processed reference
data are not stored directly in this repository. They are available from the
external link below:
